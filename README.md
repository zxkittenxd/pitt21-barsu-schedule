# Расписание БарГУ — архивная сборка

⚠️ Это **старая сборка** сайта расписания, сохранённая как отдельный репозиторий, чтобы ранее розданные ссылки продолжали работать. Снимок данных — от **6 октября 2026 года**, он больше не обновляется.

**Актуальный проект:** репозиторий [`zxkittenxd/barsu-schedule`](https://github.com/zxkittenxd/barsu-schedule)
**Актуальный сайт:** <https://zxkittenxd.github.io/barsu-schedule/>

## Чем актуальная версия отличается от этой сборки

- **157 групп и 254 преподавателя** (режимы «Группы» и «Преподаватели» со сквозной навигацией) — здесь только 121 группа
- **Автообновление данных** каждые 3 часа через GitHub Actions — здесь данные застыли на снимке
- Неделя **ПН–СБ** с меню недель, пометками замен, отметкой «идёт сейчас» и обратным отсчётом до следующей пары (по времени Минска)
- Поиск групп понимает дефисы и пробелы («ПИТТ-11» = «ПИТТ11»), офлайн-кэш в localStorage, Material-темы

## Что в этой сборке

- Расписание 121 группы БарГУ, снимок от 06.10.2026 (текущая неделя на тот момент — 2026-10-05)
- Дизайн liquid glass, живое обновление через публичные CORS-реле (ненадёжно), фолбэк — официальный фрейм rasp.barsu.by
- Один статический файл `index.html` + `data/*.json`, без бэкенда и сборки

## Старые адреса (отдают эту сборку)

- <https://zxkittenxd.github.io/pitt21-barsu-schedule/>

Для актуального расписания используйте новый адрес — университет меняет расписание каждую неделю.
